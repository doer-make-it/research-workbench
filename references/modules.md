# 六大模块详细工作流

## 1. 文献管理 (01_Literature)

**输入**：论文 PDF、阅读需求
**产出**：Zotero 引用库、文献笔记、领域动态摘要

工作流：
1. 用 Zotero 浏览器插件一键收藏 PDF + 元数据
2. 按 `references/conventions.md` 的分类建 Zotero collection（如 `甲烷氧化菌`、`生防真菌`）
3. 读完后写笔记：`YYYY-MM-DD_作者_关键词_vN.md`，存 `01_Literature/notes/`
4. 笔记结构：研究问题 → 方法 → 关键结论 → 对我的启发 → 局限
5. 定期导出 Zotero 的 BibTeX 给 Overleaf 用

检查点：
- PDF 有元数据（作者、年份、期刊），不存"未命名.pdf"
- 笔记标了是否精读 / 略读
- 引用格式统一（建议 BibTeX 自动管理，不手敲）

领域动态获取偏好：优先期刊与学报等学术来源（中文核心/学报 + SCI 期刊），产业媒体与政策动态只作补充。把刊名当关键词检索比泛主题词有效。

## 2. 实验记录 (02_Experiments)

**输入**：实验过程
**产出**：结构化实验记录、原始数据、实验照片

工作流：
1. 每次实验建一条记录：`YYYY-MM-DD_实验记录_vN.md`
2. 记录必备字段（微生物/发酵方向）：
   - 菌株编号（可追溯）
   - 培养基配方（精确到成分与浓度）
   - 培养条件（温度、转速、时长、通气）
   - 传代代数
   - 接种量、取样时间点
3. 原始数据存 `02_Experiments/raw/YYYY-MM-DD_主题/`
4. 实验照片存同目录，命名 `IMG_YYYYMMDD_HHMMSS_简述.jpg`
5. 失败实验也要记，标"失败"原因

检查点：
- 菌株编号、培养基配方、培养条件、传代代数四件套齐全
- 有重复（生物学重复/技术重复）
- 照片与记录对应得上

## 3. 数据处理 (03_Data)

**输入**：原始数据
**产出**：清洗后数据、分析脚本、图表

工作流：
1. 原始数据不动，复制到 `03_Data/processed/` 做清洗
2. Python 脚本存 `03_Data/scripts/`，命名 `YYYY-MM-DD_分析_主题.py`
3. Excel 中间数据存 `03_Data/processed/`，命名 `YYYY-MM-DD_数据集名_vN.xlsx`
4. 图表用 Origin 2024 绘制（出版级）：
   - K×N 分组柱状图带误差棒 + 显著性字母
   - 灰色配色、X 轴标签旋转（标签长时）
   - **单实例模式**：一个 Origin 实例完成所有任务，不重复启动（省 credits），仅在主动要求变更时重启
   - 输出目录用稳定别名 `数据名_最新/`，不用时间戳（方便定位最新结果）
5. 图表导出 PNG + PDF（投稿用矢量）

检查点：
- 数据有统计检验（t 检验/ANOVA + 显著性标记）
- 图表轴标签、单位齐全
- 脚本可复现（随机种子、参数注释）

## 4. 论文写作 (04_Writing)

**输入**：数据 + 文献
**产出**：论文草稿、图表、参考文献

工作流：
1. Overleaf 建项目，Git 同步到本地 `04_Writing/`
2. 章节分文件：`intro.tex` `methods.tex` `results.tex` `discussion.tex`
3. 图表从 `03_Data/数据名_最新/` 引用，不复制进 Overleaf（单一来源）
4. 引用走 BibTeX，从 Zotero 导出
5. 稿件命名 `YYYY-MM-DD_论文章节_vN.tex`

论文写作偏好：逻辑清晰、数据支撑、图表规范。微生物培养/发酵参数/杀虫毒力等实验数据要严谨，须有重复与统计检验。

精专环节（润色、引文校验、审稿模拟、返修回复）走 `nature-skills` 系列。

检查点：
- 缩写首次出现处有定义
- 参考文献格式统一（BibTeX 管理）
- 图表引用与文件对应

## 5. 知识管理 (05_Knowledge)

**输入**：所有模块产出
**产出**：Obsidian 双链笔记库、概念图

工作流：
1. Obsidian vault 指向 `05_Knowledge/`
2. 概念笔记：`概念名.md`，含定义、来源、应用、与其他概念的双链
3. 项目笔记：每个课题一个 MOC（Map of Content）
4. 周复盘：`YYYY-WW_周复盘.md`，链接本周关键笔记

检查点：
- 重要概念有双链，不孤立
- 笔记标了来源（哪篇文献/哪次实验）

## 6. 任务管理 (06_Tasks)

**输入**：待办事项、组会要求
**产出**：周计划、日待办、组会汇报材料

工作流：
1. 每周一上午固定组会工作汇报（默认 09:30，遇培训等冲突临时调整）
2. 周计划模板 `YYYY-WW_周计划.md`：
   ```
   # 第 WW 周计划 (MM-DD ~ MM-DD)
   ## 本周目标
   ## 每日安排
   - 周一: [组会 + ...]
   - 周二: [...]
   ...
   ## 风险与依赖
   ## 上周完成情况回顾
   ```
3. 组会汇报模板 `YYYY-MM-DD_组会汇报.md`：
   ```
   # 组会汇报 YYYY-MM-DD
   ## 本周进展
   - 实验:
   - 数据:
   - 论文:
   ## 遇到问题
   ## 下周计划
   ## 文献与领域动态
   ```
4. 汇报材料须前一晚或周一早上备妥

组会汇报前自检清单：
- [ ] 数据有重复与统计检验
- [ ] 图表轴标签、单位齐全
- [ ] 缩写首次出现处有定义
- [ ] 参考文献格式统一
- [ ] 菌株编号、培养基配方、培养条件、传代代数可追溯

固定日程避让：
- 周一上午 09:30 起：组会占用
- 周二晚间：课程占用（如选修课）
- 组会材料须在周一 08:30 前备妥
