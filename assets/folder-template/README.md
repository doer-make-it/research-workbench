# 目录骨架说明

这是可直接复制到新课题的空目录结构。复制后把整个 `folder-template/` 改名为你的项目名即可。

```
folder-template/
├── 01_Literature/
│   ├── pdf/
│   ├── notes/
│   └── exports/
├── 02_Experiments/
│   └── strain-register.md   # 菌株登记表种子文件
├── 03_Data/
│   ├── raw/
│   ├── processed/
│   └── scripts/
├── 04_Writing/
│   ├── tex/
│   └── figures/
├── 05_Knowledge/
│   ├── concepts/
│   ├── mocs/
│   └── reviews/
├── 06_Tasks/
│   ├── weekly/
│   ├── meetings/
│   └── todos/
└── 07_Admin/
    ├── reimbursement/
    ├── forms/
    └── notices/
```

每个目录的用途与命名规范见 `../../references/conventions.md`。

菌株登记表种子内容见 `02_Experiments/strain-register.md`。
